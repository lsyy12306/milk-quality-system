## 二、新增功能

### 2.1 奶源来源档案（sources）

企业收购业务的核心是「货从哪来」。新增 `sources` 表：

| 字段 | 说明 |
| --- | --- |
| name | 来源名称（奶站/牧场/合作社，唯一） |
| source_type | 类型：奶站 / 牧场 / 合作社 |
| contact | 联系人 |
| region | 地区 |
| note | 备注（合作情况、质量特点） |

**接口**：
- `GET /api/sources` — 来源列表（无需鉴权）
- `POST /api/sources` — 新建（需登录）
- `PUT /api/sources/{id}` — 修改
- `DELETE /api/sources/{id}` — 删除

**种子数据**：第一奶站、第二奶站、绿源牧场、康达合作社、润发牧场（5 家）。

**联动**：
- 单条预测表单增加「来源选择 + 批次号」输入，支持页面内快速新建来源
- CSV 批量预测支持接口参数统一关联，也支持 CSV 内 `Source` 列**按行匹配**来源
- 历史记录表新增「来源 / 批次号 / 建议价」列，导出 CSV 同步扩展

### 2.2 收购定价建议（优质优价）

任务书 1.1 指出传统模式「影响奶源调配与**优质优价机制**的落实」。系统按等级给出定价建议：

| 等级 | 价格系数 | 建议价（基础价 ¥4.00/kg） | 建议 |
| --- | --- | --- | --- |
| high（优） | ×1.15 | ¥4.60 | 优质奶源，优先收购 |
| medium（中） | ×1.00 | ¥4.00 | 按基础价收购并加强监控 |
| low（差） | ×0.75 | ¥3.00 | 拒收或折价，追溯来源 |

系数在 `backend/app/config.py` 的 `PRICE_FACTORS` 中可配置（按当地收购指导价调整 `BASE_PRICE`）。

**接口返回**：`POST /api/predict` 与 `/api/predict/csv` 均新增 `pricing` 字段；历史记录落库 `suggested_price`。

### 2.3 企业质量日报（Agent 第 7 工具）

`POST /api/agent/daily-report`（需登录），按日期汇总：

1. **收购概况**：记录数、等级分布（优/中/差）、建议收购总额
2. **来源质量排名**：按优质率排序（收购数、优质率、差奶数、均价）——直接回答「哪家牧场奶最好」
3. **异常与预警**：差奶占比超 20% 自动警戒；列出出现差奶的来源
4. **管理建议**：优质率最高来源可提高收购量；差奶处置建议；冷链提醒

**前端入口**：分析仪表盘右上角「生成企业日报」→ 选日期 → 查看统计表 + Markdown 原文 → 复制/下载 `.md`。

**对话入口**：智能助手输入「生成今天的日报」，Agent 意图识别为 `daily_report` 并调用工具。

### 2.4 来源管理页面（/sources）

v2.1 补充：独立的「来源管理」页面，补全来源档案的完整交互闭环。

- 左侧导航「来源管理」进入
- 统计卡片：来源总数 / 奶站 / 牧场 / 合作社
- 表格列出全部来源：名称、类型（彩色标签）、地区、联系人、备注、建档时间
- **新建来源**：弹窗表单（名称/类型/联系人/地区/备注）
- **编辑来源**：行内「编辑」按钮，回显数据后可修改
- **删除来源**：行内「删除」按钮，Popconfirm 二次确认（提示历史记录关联影响）

> 预测页表单内的「+ 新建」为快捷入口，完整管理请使用「来源管理」页面。

### 2.4 指标相关性分析

`GET /api/model/info` 新增 `correlation` 字段（7 指标 + Grade 的 8×8 Pearson 矩阵）。

**实测结论**（来自 1059 条真实数据）：
- Temperature 与 Grade **-0.418**（最强负相关）：温度越高品质越差
- Odor +0.150 / Fat +0.151 / Turbidity -0.154：与特征重要性排序互相印证
- pH 仅 0.029：线性相关弱，但 XGBoost 特征重要性第二（非线性关系）

前端「模型与特征」Tab 渲染热力图（正相关蓝 / 负相关橙红 / 强度透明）。

### 2.5 基线模型对比

同一测试集（10%，random_state=42）实测：

| 模型 | 准确率 | 宏平均 F1 |
| --- | --- | --- |
| 决策树 (DecisionTree, max_depth=6) | 94.34% | 0.9380 |
| 随机森林 (RandomForest, 200 棵) | 99.06% | 0.9895 |
| **XGBoost（本系统）** | **100%** | **1.0000** |

前端「模型与特征」Tab 展示对比表，XGBoost 行绿色高亮。

### 2.6 CSV 数据预览（两步走）

上传后**不立即预测**：
1. 前端本地解析：展示前 5 行预览表 + 列名校验（缺少必需列时警告并阻止）
2. 用户确认无误后点击「执行批量预测」才上传

### 2.7 个人中心

- `GET /api/auth/me` — 当前用户信息（ID、用户名、注册时间）
- `PUT /api/auth/me` — 修改姓名 / 邮箱
- `PUT /api/auth/password` — 修改密码（校验原密码，新密码 ≥ 6 位）

前端新增 `/profile` 页面（左侧导航「个人中心」）。

## 六、遗留与生产建议

1. **定价合规**：`PRICE_FACTORS` 为演示值，企业落地应按当地生鲜乳收购指导价与合同配置，并保留人工议价通道。
2. **数据隐私**：来源联系人信息属经营数据，生产环境应启用 HTTPS 与字段级权限。
3. **日报时区**：日报按 UTC 日期统计（SQLite 存储 UTC），国内部署建议在 `enterprise_daily_report` 中按 UTC+8 折算日期。
4. **批次追溯**：当前批次号为自由文本，企业可规范为「日期-奶站-序号」编码规则。
