# 系统架构与数据库设计

> v2.1 更新：新增 Agent 智能体层（v2.0）与企业来源档案模块（v2.1）。

## 1. 系统架构

本项目采用**前后端分离**架构：

```
┌─────────────────────────┐         ┌──────────────────────────┐         ┌──────────────────────┐
│  前端 (React + Vite)     │  HTTP   │  后端 (FastAPI)           │  载入   │  模型 (joblib)        │
│  Ant Design 5 + recharts │ ──────► │  /api/*  (CORS 开放)      │ ──────► │  Pipeline:            │
│  端口 5173 (dev)         │  /api  │  端口 8000                │         │  Scaler+XGBClassifier│
│  Vite 代理 /api→8000     │ ◄────── │  JWT 鉴权 / 匿名可预测    │         └──────────────────────┘
└─────────────────────────┘         └───────────┬──────────────┘
                                                │ ORM
                                                ▼
                                        ┌──────────────────────┐
                                        │  SQLite (sqlalchemy)  │
                                        │  milk_quality.db      │
                                        │  users/grade_records/ │
                                        │  sources/indicators/  │
                                        │  user_preferences/    │
                                        │  agent_messages       │
                                        └──────────────────────┘
```

后端内部模块（v2.1）：

```
backend/app/
├── routers/          # 7 个路由：predict / auth / history / indicators
│                     #            model / agent / sources
├── agent/            # Agent 智能体（v2.0）
│   ├── engine.py     #   推理引擎（感知→推理→行动→记忆）
│   ├── tools.py      #   7 工具（含 enterprise_daily_report）
│   └── memory.py     #   用户偏好 + 会话上下文
├── auth.py           # JWT + bcrypt（含 get_current_user_optional）
├── ml_model.py       # 模型加载 + 推理
├── seed.py           # 指标字典 + 来源档案种子
└── config.py         # 路径/JWT/定价系数（PRICE_FACTORS）
```

### 技术栈
| 层 | 技术 | 版本 |
| --- | --- | --- |
| 算法 / 模型 | Python, scikit-learn Pipeline, XGBoost | Python 3.12 |
| 后端 | FastAPI, Uvicorn, SQLAlchemy 2.0, Pydantic v2, PyJWT, bcrypt | FastAPI 0.115 |
| 前端 | React 18, Vite 5, Ant Design 5, react-router-dom 6, recharts, axios | — |
| 数据库 | SQLite 3（via sqlalchemy） | — |

### 关键设计决策
- **模型打包为 Pipeline**：`StandardScaler`（仅作用于 pH/Temperature/Colour）+ `XGBClassifier` 整体保存为 `models/milk_quality_pipeline.joblib`，预测时一次载入、一次推理，避免线上线下预处理不一致。
- **匿名可预测、登录留存历史**：`/api/predict` 使用 `auto_error=False` 的可选鉴权；未登录也能分级，登录后自动写历史。
- **CORS 开发期开放**：前端用 Bearer Token（非 Cookie），故 `allow_credentials=False` 且 `allow_origins=["*"]`，避免浏览器拦截。
- **字段命名约定**：后端接口用小写蛇形 `ph/temperature/taste/odor/fat/turbidity/colour`；数据集原始为大写首字母（含 `Temprature` 笔误），在清洗与 CSV 接口处统一纠正。
- **Agent 零外部依赖**：智能体为纯规则 + 数据分析实现（不调用外部 LLM），推理链完整可解释，单条分析 < 200ms。
- **优质优价可配置**：定价系数集中在 `config.PRICE_FACTORS`，可按地区收购指导价调整，不改业务代码。
- **旧库幂等迁移**：`database.py` 启动时执行 `_migrate_columns()`，对老数据库自动补齐新列。

## 2. 数据库设计（SQLite）

使用 SQLAlchemy 2.0 声明式映射，数据库文件 `backend/milk_quality.db`。

### 2.1 ER 关系
```
User(1) ───< GradeRecord(*) ────> Source(1)     （企业落地：来源追溯）
Indicator 为独立字典表（与记录无外键关联，仅作展示）
UserPreference / AgentMessage 为 Agent 记忆表（与 users 弱关联）
```
- 一个用户可有多条分级记录（`GradeRecord.user_id` → `User.id`）。
- `Indicator` 为指标字典（7 行），启动时由 `seed.seed()` 幂等写入。
- `Source` 为奶源来源档案（5 行种子），`GradeRecord.source_id` → `Source.id`（可空，匿名/未标注为 NULL）。

### 2.2 表结构

**users**
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, 自增 | 用户 ID |
| username | VARCHAR | UNIQUE, NOT NULL | 用户名（3–50 字符） |
| hashed_password | VARCHAR | NOT NULL | bcrypt 哈希 |
| email | VARCHAR | NULL | 邮箱（选填） |
| full_name | VARCHAR | NULL | 姓名（选填） |
| created_at | DATETIME | NOT NULL, 默认 now | 注册时间 |

**grade_records**
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, 自增 | 记录 ID |
| ph | FLOAT | NOT NULL | pH 值 |
| temperature | FLOAT | NOT NULL | 温度 °C |
| taste | INTEGER | NOT NULL | 口感 0/1 |
| odor | INTEGER | NOT NULL | 气味 0/1 |
| fat | INTEGER | NOT NULL | 脂肪 0/1 |
| turbidity | INTEGER | NOT NULL | 浑浊度 0/1 |
| colour | INTEGER | NOT NULL | 颜色 0–255 |
| predicted_grade | VARCHAR | NOT NULL | 预测等级 low/medium/high |
| confidence | FLOAT | NOT NULL | 置信度 0–1 |
| user_id | INTEGER | FK→users.id, NULL | 匿名预测为 NULL |
| source_id | INTEGER | FK→sources.id, NULL | 奶源来源（v2.1） |
| batch_no | VARCHAR(60), NULL | 批次号（v2.1） |
| suggested_price | FLOAT, NULL | 建议收购价 元/kg（v2.1） |
| created_at | DATETIME | NOT NULL, 默认 now | 预测时间 |

**indicators**
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| key | VARCHAR | PK (UNIQUE) | 字段名（如 ph） |
| name | VARCHAR | NOT NULL | 中文名（如 pH值） |
| unit | VARCHAR | NULL | 单位 |
| min_value | FLOAT | NULL | 参考下限 |
| max_value | FLOAT | NULL | 参考上限 |
| description | VARCHAR | NULL | 说明 |

**sources（v2.1 新增：奶源来源档案）**
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, 自增 | 来源 ID |
| name | VARCHAR(120) | UNIQUE, NOT NULL | 来源名称（奶站/牧场/合作社） |
| source_type | VARCHAR(20) | 默认「奶站」 | 类型：奶站/牧场/合作社 |
| contact | VARCHAR(60), NULL | — | 联系人 |
| region | VARCHAR(120), NULL | — | 地区 |
| note | TEXT, NULL | — | 备注 |
| created_at | DATETIME | NOT NULL, 默认 now | 建档时间 |

**user_preferences（v2.0：Agent 用户偏好）**
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, 自增 | — |
| user_id | INTEGER | FK→users.id, NOT NULL | 用户 |
| key / value | VARCHAR(60) / TEXT | NOT NULL | 偏好键值 |
| created_at / updated_at | DATETIME | 默认 now | 时间戳 |

**agent_messages（v2.0：Agent 会话消息）**
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK, 自增 | — |
| session_id | VARCHAR(64) | index, NOT NULL | 会话 ID |
| role | VARCHAR(20) | NOT NULL | user/assistant/system |
| content | TEXT | NOT NULL | 消息内容 |
| tool_calls | TEXT, NULL | — | JSON 序列化工具调用记录 |
| created_at | DATETIME | 默认 now | 时间戳 |

### 2.3 索引与约束
- `users.username` 唯一索引（注册查重）。
- `grade_records.user_id` 外键 + 查询按 `user_id` 过滤并结合 `created_at` 排序。
- `grade_records.source_id` 外键 + 索引（按来源统计质量）。
- `sources.name` 唯一索引（注册查重）。

> **兼容说明**：v2.1 对旧库通过 `database.py` 的 `_migrate_columns()` 启动时幂等 `ALTER TABLE ADD COLUMN`，老数据自动留空，无需手动迁移。
