# 部署手册

## 1. 环境准备
- Python 3.12（本项目使用 `.venvcn` 虚拟环境，已装依赖）
- Node.js 18+（本项目 Node 22，npm 10）
- 操作系统：Windows（本机）；以下命令在 Git Bash / PowerShell 均可

> 国内网络提示：pip 用清华镜像 `https://pypi.tuna.tsinghua.edu.cn/simple`；npm 用 `https://registry.npmmirror.com`，否则极慢。

## 2. 一键启动（推荐，Windows 用户）
项目根目录已提供批处理脚本，**双击即可启动整套产品（前后端同一端口 8000）**：

| 脚本 | 作用 |
| --- | --- |
| `启动后端.bat` | **主入口**：启动后端并自动托管前端页面，自动打开浏览器 `http://localhost:8000`。保持弹出的黑窗口开启即可，关闭它停止服务。 |
| `启动前端.bat` | 仅「开发模式」（热更新 HMR）使用。日常使用无需运行。 |

> 设计要点：**后端 `main.py` 在检测到 `frontend/dist/` 构建产物时，会直接托管前端 SPA（含 `/assets` 静态资源与 SPA 路由兜底），并把 `/api/*`、`/docs` 正常放行**。因此只需一个后端进程即可打开完整产品，无需再单独启动 Vite 开发服务器——这也避免了开发服务器意外退出导致「页面打不开」的问题。

## 3. 后端启动（手动 / 命令行）
```bash
cd milk-quality-system/backend
# 使用项目虚拟环境
../.venvcn/Scripts/uvicorn.exe app.main:app --host 127.0.0.1 --port 8000 --log-level info
```
- 首次启动会执行 `init_db()` 建表 + `seed.seed()` 写入 7 项指标。
- 验证：`curl http://127.0.0.1:8000/api/indicators` 应返回 7 项；`curl http://127.0.0.1:8000/` 应返回前端 `index.html`（`text/html`）。
- 交互文档：`http://127.0.0.1:8000/docs`

> ⚠️ 修改了 `backend/app/routers/*` 或 `main.py` 的路由后，**必须重启 uvicorn**，否则新接口会 404。

## 4. 前端启动（开发模式，可选）
```bash
cd milk-quality-system/frontend
npm install --registry=https://registry.npmmirror.com   # 仅需一次
npm run dev                                              # 启动 Vite，默认 :5173
```
- 浏览器打开 `http://127.0.0.1:5173`。
- Vite 已配置 `server.proxy['/api'] -> http://127.0.0.1:8000`，开发期无需处理跨域。

## 5. 前端构建（生产 / 静态托管）
```bash
cd milk-quality-system/frontend
npm run build        # 产物输出到 frontend/dist/
npm run preview      # 本地预览构建产物
```
- `vite.config.js` 已设 `build.emptyOutDir: false`，以规避本机安全删除机制对清空 dist 的拦截。
- 若前后端同域部署，将 `dist/` 交由 Nginx / 静态服务器托管，并把 API 请求转发到后端 :8000；或设置前端环境变量 `VITE_API_BASE` 指向后端地址。

## 6. 生产部署建议
- **反向代理**：用 Nginx 同时托管前端静态文件与 `/api` 反向代理到 FastAPI（建议开启 HTTPS）。
- **CORS**：生产环境将 `allow_origins` 改为前端真实域名，并视情况开启 `allow_credentials`。
- **鉴权加固**：为 JWT 设置合理过期时间并引入刷新机制；考虑限流防爆破。
- **数据库**：当前为单文件 SQLite，适合演示/小规模；高并发可迁移到 PostgreSQL（仅需改 `database.py` 的连接串）。
- **模型更新**：替换 `models/milk_quality_pipeline.joblib` 与 `model_metadata.json` 后重启后端即可，无需改代码。

## 7. 常见问题
| 现象 | 原因 / 解决 |
| --- | --- |
| 新接口 404 | 后端未重启，重启 uvicorn |
| `npm install` 卡住 | 未用国内镜像，改用 npmmirror |
| `vite build` 失败（safe-delete） | 已通过 `emptyOutDir:false` 规避；若仍失败，手动删除 dist 后重试 |
| 前端调接口跨域报错 | 确认 Vite 代理已配置且后端 CORS 开放；生产改具体域名 |
| 预测 422 | 字段名应为小写 `ph/temperature/...`，且取值在约束内 |
