# 牛奶品质分级系统 · UI/UX 设计文档

> 版本：v1.0.0　|　面向：Web 端（PC/平板/移动端）　|　基于 PRD v1.0 + 现有 Ant Design 5 实现

---

## 一、设计原则（5 条）

1. **简洁优先**：每页只做一件事。品质分级页不堆砌无关功能，指标输入区与结果区上下分区，视觉焦点明确。
2. **速度至上**：单条预测 P95 < 100ms，前端提交后 0.5s 内必须给出反馈。加载状态用骨架屏，禁止全局遮罩阻塞操作。
3. **够用即可**：不做过度设计。本项目无复杂业务流，表单、表格、图表均用 Ant Design 原生组件，不引入额外 UI 库。
4. **视觉降噪**：无阴影，靠留白 + 细边框分层。信息密度适中，关键数据（等级、置信度）用大字号 + 语义色突出。
5. **容错友好**：匿名可用、字段越界即时校验、CSV 列名自动纠错、错误行精确定位。用户不会卡在报错页。

## 三、布局模式

### 3.1 全局布局：侧边导航 + 内容区

```
┌─────────────────────────────────────────────────────────────┐
│  [Logo: 🥛 牛奶品质分级]        [用户头像/登录按钮]            │  ← Header 高 64px，背景 #FFFFFF，下边框 1px #E5E5EA
├──────────┬──────────────────────────────────────────────────┤
│          │                                                    │
│  侧边栏   │              内容区域（自适应宽度）                  │
│  200px   │              padding: 24px                         │
│          │                                                    │
│  品质分级 │                                                    │
│  历史记录 │                                                    │
│  指标说明 │                                                    │
│          │                                                    │
└──────────┴──────────────────────────────────────────────────┘
```

- **Header**：高 64px，固定顶部（`position: fixed; z-index: 100`）。左侧 Logo + 系统名；右侧用户区（未登录显示「登录/注册」按钮，已登录显示用户名 + 下拉菜单「退出登录」）。
- **Sider 侧边栏**：宽 200px，固定左侧。背景 `#FFFFFF`，右边框 1px `#E5E5EA`。菜单项高 48px，图标 20px + 文字 14px。激活项：文字 `#007AFF`，左侧 3px 竖线 `#007AFF`。
- **Content 内容区**：`margin-left: 200px; padding: 24px; min-height: calc(100vh - 64px); background: #F5F5F7`。内容最大宽度 1200px，居中（`margin: 0 auto`）。

### 3.2 响应式断点

| 断点 | 宽度 | 布局变化 |
| --- | --- | --- |
| **PC** | ≥ 1200px | 完整双栏：Sider 200px + Content 自适应。表单横向双列排列（指标输入 4+3 或 3+4）。 |
| **平板** | 768–1199px | Sider 收起为图标栏（宽 64px），hover 展开文字。Content `margin-left: 64px`。表单改为单列。 |
| **移动** | < 768px | Sider 完全隐藏，顶部 Header 左侧加汉堡菜单按钮，点击后 Drawer 滑出菜单。Content 全宽，`padding: 16px`。表单单列，按钮全宽。 |

> Ant Design Layout 的 `breakpoint="lg"` 和 `collapsedWidth={64}` 可直接实现平板态；移动端用 `useBreakpoint()` 检测 `< md` 时切换为 Drawer 导航。

### 5.2 特殊交互

| 场景 | 交互 | 实现说明 |
| --- | --- | --- |
| **表单提交** | 点击「开始分级」 | 按钮 loading → API 请求 → 成功：结果卡片从 `opacity:0, translateY:20px` 动画滑入（0.3s ease-out）；失败：顶部 Alert 错误信息 |
| **Tab 切换** | 点击 Tab 标签 | 内容区淡入淡出（`opacity` 过渡 0.2s），无页面刷新 |
| **CSV 上传** | 拖拽/点击上传 | Upload.Dragger 自带拖拽高亮；上传中显示进度条；上传成功文件名替换上传区 |
| **历史导出** | 点击「导出 CSV」 | 调用 API，浏览器自动下载，按钮短暂变为「下载中」+ loading，完成后 Toast「导出成功」 |
| **登录态切换** | 登录/登出 | 登录成功后全局状态更新（React Context），Sider 菜单刷新，路由跳转 /predict。登出清除 token，跳转 /login |
| **匿名预测** | 未登录点击「开始分级」 | 正常预测，结果不写入历史。登录后历史页显示「请登录后查看」 |
| **字段校验** | 输入越界 | InputNumber 的 `min/max` 阻止输入；Form 的 `rules` 失焦校验，错误文字 `#FF3B30` Caption |

## 六、页面跳转

### 6.1 核心流程

1. **首次访问** → `/predict`（品质分级页，默认「单条录入」Tab）
2. **未登录用户** → 可匿名预测，点击「历史记录」→ 提示登录 → 跳转 `/login`
3. **登录流程** → `/login` → 输入账号密码 → 成功 → 跳转 `/predict`（或之前试图访问的页面）
4. **注册流程** → `/login` 点击「去注册」→ `/register` → 注册成功 → Toast → 自动跳转 `/login`
5. **品质分级** → `/predict`：单条录入 / CSV 批量 / 模型与特征三 Tab 内切换，无页面跳转
6. **历史记录** → `/history`：查看 + 导出 CSV
7. **指标说明** → `/indicators`：纯展示页
8. **登出** → 顶部用户下拉菜单「退出登录」→ 清除 token → 跳转 `/login`

### 6.2 路由表

| 路径 | 页面 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| `/` | 重定向到 `/predict` | 否 | 根路径自动跳转 |
| `/predict` | 品质分级 | 否 | 默认 Tab「单条录入」 |
| `/history` | 历史记录 | 可选 | 未登录显示登录引导 |
| `/indicators` | 指标说明 | 否 | 纯展示 |
| `/login` | 登录 | 否 | 已登录自动跳转 /predict |
| `/register` | 注册 | 否 | 已登录自动跳转 /predict |

## 七、异常处理

### 7.1 空状态

| 场景 | 表现 | 文案 |
| --- | --- | --- |
| 历史记录页，未登录 | 居中插图 + 按钮 | 「请登录后查看历史记录」+ [去登录] |
| 历史记录页，已登录但无记录 | 居中插图 + 链接 | 「暂无分级记录」+ [去品质分级页录入] |
| 指标说明页 | 正常显示 7 项 | — |
| 模型与特征页，API 失败 | 占位卡片 + 重试按钮 | 「模型信息加载失败」+ [重新加载] |

### 7.2 加载中

| 场景 | 表现 |
| --- | --- |
| 页面初始加载 | 无（React 路由切换快，无需全局 loading） |
| 表单提交中 | 按钮 `loading` prop，禁用输入 |
| 表格数据加载 | Ant Design `Table` 自带骨架屏（`loading` prop） |
| 图表加载 | 卡片内居中 Spin + 「加载中...」 |
| CSV 上传 | Upload.Dragger 自带进度条 |

### 7.3 错误提示

| 场景 | 表现 | 位置 |
| --- | --- | --- |
| 网络断开 | 顶部红色 Alert 条 | 页面顶部固定 |
| 预测接口 422 | 字段下方红色文字 | 对应表单字段下方 |
| 预测接口 500 | 顶部红色 Alert「服务异常，请稍后重试」 | 页面顶部 |
| CSV 缺列/格式错误 | Alert type="error" + 错误行明细 | 结果卡片顶部 |
| 登录 401 | 密码框下方红色文字「用户名或密码错误」 | 密码框下方 |
| 注册 400（用户名已存在） | 用户名框下方红色文字 | 用户名框下方 |
| 历史导出失败 | Toast type="error"「导出失败」 | 右上角 |

## 九、与现有代码的对应关系

本设计文档基于现有 Ant Design 5 实现，主要调整方向：

| 设计点 | 现有实现 | 本设计建议 |
| --- | --- | --- |
| 色彩 | Ant Design 默认蓝 `#1677FF` | 统一为 Apple 蓝 `#007AFF`，语义色按等级映射 |
| 背景 | 默认白色 | 页面 `#F5F5F7` + 卡片 `#FFFFFF`，增加层次感 |
| 边框 | 无或默认 | 卡片统一加 1px `#E5E5EA` 边框 |
| 表单布局 | 单列 | PC 三列 Grid，提升空间利用率 |
| 结果展示 | Tag + Statistic | 增加动画滑入、概率 Progress 条 |
| 响应式 | 未明确 | 补充 PC/平板/移动三断点规则 |

> 现有代码（`frontend/src/pages/*.jsx`、`components/*.jsx`）可直接按本设计的 Token 和布局规则逐步重构，无需更换 UI 库。
