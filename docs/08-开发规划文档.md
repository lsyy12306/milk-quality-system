## 一、开发总纲

### 1.1 项目定位
牛奶品质分级系统是一个**前后端分离的轻量级机器学习 Web 应用**，核心能力为：输入 7 项牛奶理化指标 → XGBoost 模型自动分级（low/medium/high）→ 返回等级、置信度、三分类概率。附带用户鉴权、历史记录、CSV 批量处理、模型可解释性可视化。

### 1.2 技术选型（已锁定）

| 层级 | 技术 | 版本 | 选型理由 |
| --- | --- | --- | --- |
| 算法/模型 | Python + scikit-learn Pipeline + XGBoost | Python 3.12 | Pipeline 打包预处理+模型，避免线上线下不一致；XGBoost 多分类效果优异 |
| 后端 | FastAPI + Uvicorn + SQLAlchemy 2.0 + Pydantic v2 + PyJWT + bcrypt | FastAPI 0.115 | 异步高性能、自动 Swagger 文档、类型安全、Python 生态成熟 |
| 前端 | React 18 + Vite 5 + Ant Design 5 + react-router-dom 6 + recharts + axios | — | 组件库丰富、构建快、图表能力足、社区活跃 |
| 数据库 | SQLite 3（via SQLAlchemy） | — | 零配置、单文件、适合演示/小规模；高并发可迁 PostgreSQL |
| 部署 | 开发期 Vite 代理；生产 Nginx 反向代理 | — | 标准前后端分离部署模式 |

### 1.3 开发原则
1. **接口先行**：后端 API 契约确定后，前后端可并行开发。
2. **模型即服务**：模型以 joblib 文件形式独立存在，后端只负责加载和推理，不耦合训练逻辑。
3. **匿名友好**：核心预测功能无需登录，降低使用门槛；登录后增值功能（历史记录）自动解锁。
4. **防御性编程**：所有外部输入（表单、CSV、JWT）均做校验和异常处理。

## 四、API 契约

### 4.1 接口清单（已固化）

| # | 方法 | 路径 | 鉴权 | 用途 |
| --- | --- | --- | --- | --- |
| 1 | GET | `/` | 否 | 健康检查 |
| 2 | GET | `/api/indicators` | 否 | 指标字典 |
| 3 | POST | `/api/predict` | 可选 | 单条预测 |
| 4 | POST | `/api/predict/csv` | 可选 | CSV 批量 |
| 5 | POST | `/api/auth/register` | 否 | 注册 |
| 6 | POST | `/api/auth/login` | 否 | 登录 |
| 7 | GET | `/api/history` | 是 | 历史记录 |
| 8 | GET | `/api/history/export` | 是 | 导出 CSV |
| 9 | GET | `/api/model/info` | 否 | 模型信息 |

### 4.2 核心契约详情

#### 单条预测 /api/predict

**Request** (`application/json`):
```json
{
  "ph": 6.6,
  "temperature": 35,
  "taste": 1,
  "odor": 0,
  "fat": 1,
  "turbidity": 1,
  "colour": 255
}
```
字段约束：`ph` 0–14；`temperature` 0–100；`taste/odor/fat/turbidity` 0/1；`colour` 0–255。

**Response 200**:
```json
{
  "grade": "high",
  "confidence": 0.999,
  "probabilities": { "low": 0.0003, "medium": 0.0004, "high": 0.999 }
}
```

**Response 422**: Pydantic 校验错误（字段缺失/越界）。

#### 用户登录 /api/auth/login

**Request**:
```json
{ "username": "alice", "password": "secret123" }
```

**Response 200**:
```json
{ "access_token": "<jwt>", "token_type": "bearer" }
```

**Response 401**: 用户名或密码错误。

#### 模型信息 /api/model/info

**Response 200**:
```json
{
  "model_type": "XGBoost (sklearn Pipeline: StandardScaler + XGBClassifier)",
  "n_samples": 1059,
  "features": ["pH","Temperature","Colour","Taste","Odor","Fat","Turbidity"],
  "class_order": ["low","medium","high"],
  "test_accuracy": 1.0,
  "test_macro_f1": 1.0,
  "test_f1_per_class": {"low":1.0,"medium":1.0,"high":1.0},
  "feature_importance": {"Turbidity":0.274,"pH":0.200,"Fat":0.177,"Temperature":0.149,"Odor":0.084,"Taste":0.073,"Colour":0.044},
  "best_params": {"max_depth":3,"learning_rate":0.2,"n_estimators":300,"subsample":0.8,"colsample_bytree":0.8}
}
```

### 4.3 错误码统一

| 状态码 | 含义 | 前端处理 |
| --- | --- | --- |
| 200 | 成功 | 正常渲染 |
| 400 | 业务错误 | 字段下方红色提示 / Alert |
| 401 | 未认证 | 跳转登录页 |
| 422 | 校验失败 | 表单字段红色提示 |
| 500 | 服务错误 | 顶部 Alert「服务异常，请稍后重试」 |

## 五、开发规范

### 5.1 代码规范

- **Python**：PEP 8，类型注解（FastAPI 已强制），函数 docstring。
- **JavaScript/JSX**：ESLint + Prettier（推荐），函数式组件 + Hooks，props 用 PropTypes 或 JSDoc。
- **命名**：
  - 后端：snake_case（`predict_single`, `grade_records`）
  - 前端：camelCase（`handleSubmit`, `predictedGrade`）
  - 组件：PascalCase（`GradeResult`, `FeatureImportanceChart`）
- **文件组织**：按功能分层（`pages/`, `components/`, `routers/`, `schemas/`），不混合。

### 5.2 Git 规范

- 分支：`main`（稳定）+ `dev`（开发）+ `feature/*`（功能）。
- 提交信息：`type(scope): subject`，如 `feat(predict): add CSV batch upload`。
- 类型：`feat` / `fix` / `docs` / `style` / `refactor` / `test` / `chore`。

### 5.3 接口版本管理

- 当前版本：v1（无显式版本前缀，如 `/api/v1/predict` 可后续引入）。
- 破坏性变更时必须升级版本，保留旧版本至少一个迭代周期。

### 5.4 环境变量

| 变量 | 用途 | 示例 |
| --- | --- | --- |
| `SECRET_KEY` | JWT 签名密钥 | 生产必须替换为强随机串 |
| `DATABASE_URL` | 数据库连接 | `sqlite:///./milk_quality.db` |
| `MODEL_PATH` | 模型文件路径 | `models/milk_quality_pipeline.joblib` |
| `VITE_API_BASE` | 前端 API 基地址 | 生产：`https://api.example.com` |

## 六、风险矩阵

| 风险 | 可能性 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| **数据集 License 为 Unknown，商用受限** | 高 | 高 | 文档明确标注；商用前联系发布者确认授权或替换数据 |
| **模型在真实奶源上泛化不足** | 中 | 高 | UI 内置免责声明；建议后续收集真实场景数据重新训练 |
| **SQLite 高并发瓶颈** | 中 | 中 | 演示/小规模无碍；高并发时迁移 PostgreSQL（仅需改连接串） |
| **JWT 密钥泄露** | 低 | 高 | 生产用环境变量注入强随机密钥；定期轮换 |
| **前端构建 safe-delete 拦截** | 中（本机） | 低 | vite.config.js 已设 `emptyOutDir: false` |
| **XGBoost Python 3.13 不兼容** | 低 | 中 | 锁定 Python 3.12；CI/CD 指定版本 |
| **pip/npm 国内网络慢** | 高（国内） | 低 | 使用清华/阿里镜像（已配置） |
| **修改路由后未重启后端导致 404** | 中 | 低 | 文档强调；开发脚本加入自动重启（如 `--reload`） |
