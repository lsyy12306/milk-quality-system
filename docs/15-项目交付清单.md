## 七、启动方式（已修复路径 bug + 后端托管前端）

> **v2.1 重大改进**：后端 `main.py` 在检测到 `frontend/dist/` 时**直接托管前端 SPA**（含 `/assets` 与 SPA 路由兜底），并放行 `/api/*` 与 `/docs`。因此**只需一个后端进程即可打开完整产品**，无需再单独启动脆弱的 Vite 开发服务器（这也消除了「开发服务器意外退出导致页面打不开」的反复问题）。前端 API 走相对路径（未设 `VITE_API_BASE`），天然适配同域托管。

**最简单（推荐）**：双击 `启动后端.bat` → 自动开浏览器 `http://localhost:8000`，保持黑窗口开启即可。

**开发模式（可选）**：先双击 `启动后端.bat`，再双击 `启动前端.bat`，访问 `http://localhost:5173`（热更新 HMR）。
