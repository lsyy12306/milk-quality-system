# 产品需求文档（PRD）与项目说明

## 1. 项目背景
乳制品行业中，奶源品质的初步分级直接关系到收购定价与生产调度。传统分级依赖人工经验，效率低且标准不统一。本项目基于一份公开的牛奶理化指标数据集，构建一套**轻量级机器学习分级 Web 应用**：输入 7 项理化指标，自动输出品质等级（低/中/高）及置信度，并提供历史记录与批量处理能力。

## 2. 目标与范围
- **目标**：用机器学习模型对牛奶品质做三级（low/medium/high）自动分级，准确率 ≥ 85%，各类别 F1 ≥ 0.80。
- **范围**（本项目交付）：
  - 单条指标录入 → 实时分级 + 各级概率
  - CSV 批量上传 → 逐行预测 + 结果表
  - 用户注册 / 登录（JWT）
  - 分级历史记录查看与导出（CSV）
  - 指标字典与模型性能可视化
- **非范围**（明确不做）：食品安全实验室检测（掺假/抗生素/微生物）、物联网实时采集、多租户与企业级权限。

## 3. 目标用户
- 奶站 / 收奶点的品质初筛员
- 乳制品企业的品控与调度人员
- 课程作业 / 原型演示场景下的学习者

## 4. 核心功能列表
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 单条预测 | 录入 7 项指标，返回等级 + 置信度 + 三分类概率 |
| F2 | CSV 批量预测 | 上传含表头的 CSV（两步预览确认），逐行预测并展示结果表；Source 列按行匹配来源 |
| F3 | 用户鉴权 | 注册 / 登录，Bearer Token 鉴权；匿名也可预测（不留存历史） |
| F4 | 历史记录 | 登录用户查看本人分级历史，支持分页；含来源、批次号、建议价 |
| F5 | 历史导出 | 将本人历史导出为带 UTF-8 BOM 的 CSV（兼容 Excel） |
| F6 | 指标字典 | 展示 7 项指标含义、单位与参考范围 |
| F7 | 模型信息 | 展示模型类型、样本量、测试准确率 / 宏 F1、各类 F1、特征重要性、相关性矩阵、基线模型对比 |
| F8 | Agent 智能体（v2.0） | 根因分析、改进建议、趋势分析、异常检测、报告生成、知识问答、企业日报；对话式交互 |
| F9 | 奶源来源档案（v2.1） | 奶站/牧场/合作社档案管理（新建/编辑/删除），预测记录按来源与批次追溯 |
| F10 | 优质优价定价建议（v2.1） | 按等级给出收购建议价（优×1.15 / 中×1.00 / 差×0.75，系数可配置） |
| F11 | 企业质量日报（v2.1） | 按日期汇总：等级分布、来源质量排名、差奶预警、建议收购总额；支持复制/下载 Markdown |
| F12 | 个人中心（v2.1） | 查看/修改个人资料、修改密码 |

## 5. 非功能需求
- **性能**：单条预测 P95 < 100ms（实测 ~17ms）；批量按行处理（单条 ~6.4ms）；Agent 单条分析 < 200ms。
- **兼容性**：现代浏览器（Chrome/Edge/Firefox）；前端响应式布局。
- **可维护性**：前后端分离，模型以 joblib 打包，配置集中（含定价系数）。
- **安全**：密码 bcrypt 哈希存储；JWT 短时令牌；CORS 开发期开放、生产应限定域名。

## 7. 里程碑（实际推进）
1. 阶段一：数据获取、环境搭建、EDA、XGBoost 基线（可行性验证）✅
2. 阶段二：特征工程、模型调参（GridSearchCV + 类别加权）✅
3. 阶段三：FastAPI 后端（23 接口）+ React 前端（Ant Design，9 页面，含登录/注册）✅
4. 阶段四：Agent 智能体升级（v2.0）✅
5. 阶段五：企业落地增强（v2.1：来源档案/优质优价/企业日报）✅
6. 阶段六：文档与交付物（本文档所在阶段）✅

## 8. 需求可追溯性（任务书 → 实现）
| 任务书要点 | 对应实现 |
| --- | --- |
| 7 项理化指标输入 | PredictRequest 字段 + 前端表单 |
| 三级分类 | XGBoost multi:softprob，class_order=[low,medium,high] |
| ≥85% 准确率 | 实测 100% |
| 后端 FastAPI | backend/app（23 接口） |
| 前端 React + UI 库 | frontend（React18 + Vite + Ant Design5，9 页面，含登录/注册） |
| 数据库 sqlite3 | SQLAlchemy + SQLite（users/grade_records/sources/indicators/user_preferences/agent_messages） |
