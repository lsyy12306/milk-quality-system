## 2. 字段说明

| 字段（清洗后） | 原始列名 | 类型 | 取值域 / 含义 | 在模型中的角色 |
| --- | --- | --- | --- | --- |
| `pH` | pH | 连续 | 3.0 – 9.5（实际多集中在 6.25–6.90） | 自变量（标准化） |
| `Temperature` | Temprature ⚠️ | 连续 | 34 – 90 °C（实际多集中在 34–45.20） | 自变量（标准化） |
| `Taste` | Taste | 二值 | 0 = 差(Bad)，1 = 好(Good) | 自变量（直通） |
| `Odor` | Odor | 二值 | 0 = 差(Bad)，1 = 好(Good) | 自变量（直通） |
| `Fat` | Fat | 二值 | 0 = 低(Low)，1 = 高(High) | 自变量（直通） |
| `Turbidity` | Turbidity | 二值 | 0 = 低(Low)，1 = 高(High) | 自变量（直通） |
| `Colour` | Colour | 连续整数 | 240 – 255 | 自变量（标准化） |
| `Grade` | Grade | 类别（目标） | `low`(差) / `medium`(一般) / `high`(优) | **预测目标** |

### ⚠️ 列名拼写注意事项
原始数据中温度列拼写为 **`Temprature`**（少了一个 e），属数据本身的笔误。本项目在数据清洗阶段统一修正为 `Temperature`，并在 CSV 批量预测接口中做容错（自动把 `temprature` / `Temprature` 等变体清洗为标准名），避免用户上传原始文件时报「缺少列」。

## 3. 业务语义
- 当 `Taste`、`Odor`、`Fat`、`Turbidity` 均满足最优条件（取值为 1）时，牛奶品质更可能被评定为高（high）；任一为 0 则会拉低等级。
- `pH` 与 `Temperature` 为实际测量值（连续），其余四项为合格/不合格式的质量标志。
- 目标变量 `Grade` 综合反映上述参数，用于奶源收购与生产环节的品质初筛。

## 4. 数据质量小结
- 无缺失值（页面声明 + 本项目 EDA 双重确认）。
- 轻度类别不平衡（low:medium:high ≈ 41:35:24），采用类别加权训练缓解。
- 特征重要性（XGBoost）：`Turbidity > pH > Fat > Temperature > Odor > Taste > Colour`，浑浊度与 pH 对分级影响最大。

## 5. 数据使用边界
本数据用于**品质初筛模型训练与演示**，不覆盖食品安全的核心检测项（掺假、抗生素残留、微生物指标等）。系统 UI 已内置免责声明，提示结果需结合实验室检测复核。
