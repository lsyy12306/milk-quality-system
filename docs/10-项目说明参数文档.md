## 一、项目概述

| 项目 | 说明 |
|------|------|
| **项目名称** | 牛奶品质分级系统（Milk Quality Grading System） |
| **版本** | V1.0.0 |
| **开发时间** | 2026-10-15 ~ 2026-10-19 |
| **开发模式** | 人机协作（AI 助手 + 开发者） |
| **项目类型** | 机器学习 Web 应用（B/S 架构） |
| **目标用户** | 奶站收购员、乳企质检人员 |

### 1.1 项目背景

生鲜乳品质直接关系乳制品质量安全。传统实验室检测周期长，收购现场缺乏快速初筛手段。本项目基于 7 项理化指标（pH、温度、口感、气味、脂肪、浑浊度、颜色），利用 XGBoost 机器学习模型实现牛奶品质的快速三级分级（低/中/高），通过浏览器即可完成单条录入或 CSV 批量分级。

### 1.2 核心成果

| 指标 | 任务书要求 | 实际值 |
|------|-----------|--------|
| 测试集准确率 | ≥ 85% | **100%** |
| 宏平均 F1 | ≥ 0.80 | **1.000** |
| 各类别 F1 | ≥ 0.80 | **1.000 / 1.000 / 1.000** |
| 单条预测响应 | — | **~15ms** |
| 后端接口可用率 | — | **9/9 全部 200** |

## 五、运行方式

### 5.1 环境要求

- Python 3.12+
- Node.js 18+
- 操作系统：Windows / macOS / Linux

### 5.2 启动后端

```bash
cd milk-quality-system/backend
# 创建虚拟环境（首次）
python -m venv .venvcn
.venvcn/Scripts/activate  # Windows
# 安装依赖（首次）
pip install -r requirements.txt
# 启动服务
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

后端文档：`http://127.0.0.1:8000/docs`

### 5.3 启动前端

```bash
cd milk-quality-system/frontend
# 安装依赖（首次）
npm install
# 开发模式
npm run dev
# 生产构建
npm run build
```

前端地址：`http://127.0.0.1:5173`

## 七、注意事项

1. **食品品质免责声明**：本系统分级结果仅供奶源收购初筛参考，不构成食品安全检验合格依据。
2. **数据隐私**：上传的理化检测数据可能涉及生产经营信息，生产环境应启用 HTTPS 加密传输。
3. **模型局限**：仅基于 7 项理化指标训练，对掺假掺杂、抗生素残留等问题不具备检测能力。
4. **License 风险**：Kaggle 数据集 License = Unknown，商用前需确认授权。
5. **安全提醒**：`SECRET_KEY` 为占位符，生产环境必须替换为强随机字符串。
6. **定价合规**：`PRICE_FACTORS` 为演示值，企业落地应按当地收购指导价与合同配置，保留人工议价通道。
