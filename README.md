# 牛奶品质分级系统

基于机器学习的牛奶品质三级（低 / 中 / 高）自动分级 Web 应用。输入 7 项理化指标，输出品质等级、置信度与三分类概率，并提供单条预测、CSV 批量预测、用户鉴权、历史记录与导出、指标字典与模型可视化。

**v2.1 企业落地版**：在预测能力之上新增 Agent 智能体（根因分析/改进建议/趋势/异常/报告/知识问答/企业日报）与**企业收购场景能力**（奶源来源档案、优质优价定价建议、企业质量日报），与企业实际业务挂钩。

## 技术栈
- **算法 / 模型**：Python 3.12 · scikit-learn Pipeline（StandardScaler + XGBoost）
- **后端**：FastAPI · Uvicorn · SQLAlchemy 2.0 · SQLite · JWT(bcrypt)
- **前端**：React 18 · Vite 5 · Ant Design 5 · recharts · axios
- **数据**：Kaggle [cpluzshrijayan/milkquality](https://www.kaggle.com/datasets/cpluzshrijayan/milkquality)（1059 行，License: Unknown）

## 模型效果（实测）
- 测试集准确率 **100%**（任务书要求 ≥ 85%）✅
- 各类别 F1 **1.00**（任务书要求 ≥ 0.80）✅
- CV 宏平均 F1 **0.9976**
- 基线对比：决策树 94.34% / 随机森林 99.06% / **XGBoost 100%**
- 特征重要性：Turbidity(27.4%) > pH(20.0%) > Fat(17.7%) > Temperature(14.9%) > Odor(8.4%) > Taste(7.3%) > Colour(4.4%)

## 企业能力速览
- **来源档案**：奶站/牧场档案管理，预测记录可按来源、批次追溯
- **优质优价**：按等级自动给出收购定价建议（优 ×1.15 / 中 ×1.00 / 差 ×0.75，系数可配置）
- **企业日报**：一键生成收购质量日报（等级分布、来源排名、预警、建议总额），支持复制/下载
- **Agent 智能体**：6 大分析工具 + 对话交互，推理链可解释，零外部 LLM 依赖

## 快速开始

### 一键启动（推荐，Windows）
双击项目根目录的 **`启动后端.bat`** 即可——它会启动后端并自动托管前端页面，自动打开浏览器 `http://localhost:8000`。保持弹出的黑窗口开启即可，关闭它停止服务。**无需再单独启动前端**。

### 后端（:8000，手动）
```bash
cd backend
../.venvcn/Scripts/uvicorn.exe app.main:app --host 127.0.0.1 --port 8000
```
> 后端 `main.py` 在检测到 `frontend/dist/` 时会直接托管前端 SPA（含 `/assets` 与 SPA 路由兜底），并放行 `/api/*`、`/docs`，因此单进程即可打开完整产品。

### 前端开发模式（可选，:5173）
```bash
cd frontend
npm install --registry=https://registry.npmmirror.com
npm run dev
```
浏览器打开 http://127.0.0.1:5173 → 注册账号 → 登录 → 分级。（日常使用推荐上面的「一键启动」即可。）

> 提示：修改后端路由后需重启 uvicorn；国内网络请用上述镜像源。
